# 🚦 Smart Traffic AI - Chennai

Real-time Smart Traffic Management System using AI for Chennai Smart City.

### Features
- Vehicle Detection using YOLOv8
- Real-time Counting (Car, Bus, Truck, Bike)
- Interactive Web Dashboard with Streamlit
- Traffic Density Graph & Analytics

### Tech Stack
Python, YOLOv8, OpenCV, Streamlit, Pandas

### How to Run
```bash
pip install -r requirements.txt
python -m streamlit run dashboard.py
